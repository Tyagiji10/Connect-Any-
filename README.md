# Connect Any 🎧⚡

**Connect Any** is a modern, feature-rich Android application designed to seamlessly manage, connect, and monitor your Bluetooth devices. Built with **Jetpack Compose** and modern Android architecture, it provides an intuitive user interface with beautiful, customizable popups and robust background management.

## ✨ Features

- **Seamless Bluetooth Management:** Quickly view, connect, and manage all your bonded Bluetooth devices.
- **Dynamic Popups:** Get AirPods-style connection popups when your devices connect. Choose from multiple themes:
  - Drop Popup
  - Gaming Popup
  - Glass Popup
  - Magnetic Popup
  - Minimal Popup
- **Companion Device Support:** Native integration with Android's Companion Device Manager for reliable connections.
- **Battery & Health Monitoring:** Keep track of your connected device's battery levels.
- **Widgets & Quick Settings Tiles:** Control and view your devices directly from your home screen or quick settings panel.
- **Overlay Service:** System-level overlays for uninterrupted device management.
- **Modern UI/UX:** Built entirely with Jetpack Compose using Material Design 3 guidelines.

## 🛠️ Tech Stack & Architecture

- **UI:** Jetpack Compose, Material Design 3
- **Architecture:** Clean Architecture + MVVM (Model-View-ViewModel)
- **Concurrency:** Kotlin Coroutines & Flow
- **Local Storage:** Room Database
- **Dependency Injection:** Hilt / Dagger
- **Background Processing:** Foreground Services, Broadcast Receivers
- **Testing:** JUnit4, Mockito (Unit testing for ViewModels and State Machines)

## 🚀 Getting Started

### Prerequisites
- Android Studio Iguana (or newer)
- Kotlin 1.9.0+
- Minimum SDK: 26 (Android 8.0)
- Target SDK: 34 (Android 14)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Tyagiji10/Connect-Any-.git
   ```
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Build and run the app on an emulator or physical device.
